About PokéCollector

Your ultimate Pokémon TCG collection manager

PokéCollector is a modern, full-stack web application designed for Pokémon Trading Card Game enthusiasts. It allows trainers to seamlessly explore full card sets, filter by specific metadata (Name, Set, Illustrator, Rarity), manage personal Collections and Wishlists, and experience dynamic database-driven rarity sorting.

Open Source Repositories

MustacheOfDeath / PokemonTCG
Backend

Spring Boot 3 REST API managing card collections, user authentication, and custom data processing.

MustacheOfDeath / PokemonTCG-FRONTEND
Frontend

Angular 17+ single-page application built with Tailwind CSS, supporting dark/light mode and dynamic filters.

PokemonTCG / pokemon-tcg-data
Data Source

Comprehensive JSON data source for Pokémon TCG sets, cards, images, and expansion stats.
